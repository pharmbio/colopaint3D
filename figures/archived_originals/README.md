# Archived original panels

The Fig 4 UMAP PDFs as written on **2026-01-13**, copied from
`colopaint3D/spher_colo52_v1/3_Figure4/PCAUMAP/result-images/`. These are the figures in
the paper. They are **not** regenerated by `run_all.py` and are deliberately named so
`--verify` skips them — the regenerated panels are `figures/Fig4/Fig4a-d.pdf`.

They are kept because the current tree cannot re-derive them, for two datable reasons
(see `provenance/KNOWN_ISSUES.md`):

* `PCAUMAP_pathway_v2.ipynb` was last edited 2026-01-15, **two days after** these PDFs
  were written, so the aggregates panels come from code that no longer exists.
* `grit_data_MIP_HCT116.parquet` was regenerated 2026-08-14, **seven months after**, so
  the MIP panels' input no longer exists either. No January-2026 copy survives anywhere
  on disk, and the fork's older table does not reproduce them.
